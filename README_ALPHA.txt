Thanks for testing Ashbane! This is an early alpha build.

--------------------------------------------------------------------------------
QUICK START (No install required!)
--------------------------------------------------------------------------------

1. Extract this folder anywhere (Desktop is fine)
2. Double-click "Ashbane.exe" - that's it!
3. Click "Play as Guest" to jump right in

Note: Keep all files together in the same folder.

--------------------------------------------------------------------------------
CONTROLS
--------------------------------------------------------------------------------

  Movement:       WASD or Arrow Keys
  Attack:         Left Mouse Button
  Dodge/Roll:     Spacebar
  Interact:       E (talk to NPCs, open chests)
  Inventory:      I
  Character:      C
  Map:            M
  Chat:           Enter

--------------------------------------------------------------------------------
GETTING STARTED
--------------------------------------------------------------------------------

- You spawn at a campfire (safe zone)
- Talk to the Wanderer NPC nearby to buy starter gear
- Skeletons roam the lands - kill them for XP and loot
- Stay near lava pools for tougher enemies and better drops
- The eastern lands are locked for this alpha test
