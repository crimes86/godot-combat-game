# Forge Item Philosophy & Selection Guide

## Core Philosophy

Forged items exist to **validate a player's gaming history** and spark curiosity, NOT to replace Dreadland's native progression system.

### The Twinking System

Forged items are **Dreadland's twinking system**. Unlike native gear with level requirements:

```
FORGED ITEMS:
━━━━━━━━━━━━━
✓ No level requirements
✓ Available from character level 1
✓ Full power immediately upon forging
✓ Tradeable between players
✓ Backed by real achievement provenance

Result: A player who beat Malenia in Elden Ring gets lifesteal
        and Waterfowl Dance from minute one in Dreadland.
```

This is **intentional**. New players without achievements will:
1. Get stomped by twinks initially
2. See powerful forged items and wonder "How do I get that?"
3. Either link their own achievements OR grind native gear OR buy from other players

The system creates asymmetry that drives engagement, not unfairness—because paths to equal power exist.

### The Pitch Test

Every achievement we map must pass this test:

> "A casual gamer hears about Ashbane/Dreadland and thinks: 'Wait, I did [X] in [Game] years ago - that was hard as hell. I wonder if that counts for something?'"

If an achievement doesn't make someone think "that HAS to be in there," it shouldn't be.

### Item Hierarchy (Sacred)

```
DREADLAND NATIVE ITEMS (Endgame King)
    ↑ Always the ultimate flex
    │
LEGENDARY FORGED ITEMS (Prestigious Visitors)
    ↑ "Holy shit, you did THAT?"
    │
EPIC FORGED ITEMS (Respected History)
    ↑ "Nice, you've been around"
    │
RARE FORGED ITEMS (Conversation Starters)
    ↑ "Oh cool, what's that from?"
    │
(Common/Uncommon cannot be forged - display only)
```

**Power Philosophy**: Forged items provide REAL combat advantages through passive effects and active abilities. A player with prestigious forged gear has earned that power through external gaming achievements. However, every forged effect MUST have a native Dreadland equivalent—pure Dreadland grinders can achieve equal power through native gameplay.

```
POWER BALANCE:
━━━━━━━━━━━━━━
Full Forged Loadout    ══════════    Full Native Loadout
(5 prestigious items)                (5 endgame items)
       ║                                    ║
       ║ Equal Maximum Power                ║
       ╚════════════════════════════════════╝

Average player with no forged items:
→ Will be at disadvantage until they grind native equivalents
→ This is intentional - achievements should MEAN something
```

## Achievement Selection Criteria

### The "Holy Shit" Factor (Required)

An achievement qualifies for forge mapping if it meets ANY of these:

| Criterion | Example | Why It Works |
|-----------|---------|--------------|
| **Community Legend** | Dark Souls "The Dark Soul" | Everyone knows this is brutal |
| **Speedrun Recognition** | Hades "32 Heat Clear" | Skill-based, verifiable |
| **Completion Milestone** | Hollow Knight "112% Completion" | Time investment + skill |
| **Boss Kill Fame** | Elden Ring "Malenia Defeated" | Meme-tier difficulty |
| **Legacy/Unobtainable** | WoW "Realm First" | Literally impossible now |
| **Secret/Hidden** | Game's hardest secret achievement | Discovery + execution |

### Disqualifiers (Auto-Reject)

- Tutorial completions
- Story progression (just playing the game)
- Collectible hunts with no skill requirement
- Achievements > 30% global unlock (too common)
- Grinding-only achievements (time ≠ skill)

### The 5-Second Recognition Test

Ask: "If I say '[Achievement Name]' to someone who played that game, do they immediately nod in respect?"

- YES → Candidate for mapping
- MAYBE → Needs strong item design to compensate
- NO → Reject

## External vs Native Item Balance

### Target Ratio

```
In a player's typical endgame loadout:
├── 70-80% Dreadland Native Items (earned in-game)
├── 15-25% Forged Items (achievement history)
└── 5-10% Special/Event Items (seasonal, etc.)
```

### Why This Ratio?

1. **Dreadland Must Feel Complete Alone** - A player with ZERO external achievements should have a full, satisfying gear progression with EQUAL power ceiling
2. **Forged Items Are Shortcuts, Not Exclusives** - They provide power faster, but not unique power
3. **Scarcity = Value** - Fewer forge-mapped achievements = each one matters more
4. **Curiosity Driver** - When you see someone with a forge item, it's notable because it's rare
5. **Incentive Loop** - Players see powerful forged items → wonder what achievement → may grind that game → return with new gear

### Total Forge Item Target

**Phase 1 Target: 30-40 total mapped achievements across ALL providers**

That's it. Not 200. Not 500. Thirty to forty carefully curated moments of gaming history.

Forged items should cover different slots to avoid "everyone has the same sword":

| Slot | Target Count | Notes |
|------|--------------|-------|

| Head Armor | 4-6 | Crowns, helms, hats |

| Capes | 2-3 | Reserved for TRUE prestige |
| Shields | 2-3 | |
| Body Armor | 2-4 | Rare - mostly native |

**Body armor intentionally limited** - We want native Dreadland armor to dominate the visual identity.

## Effect & Ability System

Forged items grant real combat power through two mechanisms:

### Passive Effects (Always Active)

Each item can have 1-3 passive effects that trigger automatically:

| Effect Type | Example | Forged Source | Native Equivalent |
|-------------|---------|---------------|-------------------|
| **Lifesteal** | Heal 5% of damage dealt | Hand of Malenia | Vampiric Enchantment |
| **Death Prevention** | Survive lethal hit (1/battle) | Elden Lord Crown | Phoenix Blessing |
| **Damage Boost** | +10% damage to bosses | Moonlight Greatsword | Slayer's Mark |
| **Crit Chance** | +8% critical hit chance | Chaos Blade | Precision Gem |
| **Defense Aura** | -15% incoming damage | Great Tortoise Shell | Iron Will |

### Active Abilities (Ability Bar)

Some legendary items grant active abilities with cooldowns:

| Ability | Source Item | Effect | Cooldown |
|---------|-------------|--------|----------|
| Waterfowl Dance | Hand of Malenia | 12-hit flurry (15 dmg each) | 30s |
| Mortal Draw | Sekiro Blade | Unblockable 150% damage strike | 25s |
| Chaos Storm | Chaos Blade | AoE fire damage | 45s |

### Power Budget Rules

```
SLOT LIMITS:
├── Passive Effect Slots: 3 maximum (from all equipped items)
├── Active Ability Slots: 2 from forged items (ability bar has 4-6 total)
└── Effect Stacking: Same effect from multiple items = NO stack

POWER SCALING:
└── Effect power scales with effort_score of source achievement
    ├── Legendary (80-100 effort): Full power effects
    ├── Epic (60-79 effort): 75% power effects
    └── Rare (40-59 effort): 50% power effects
```

See `docs/FORGE_ITEM_EFFECTS.md` for complete effect specifications.

## Trading & Economy

### Frictionless In-Game Trading

Forged items are **fully tradeable** in-game, just like any MMO:

```
TRADING FLOW:
━━━━━━━━━━━━━
Player A: "WTS Hand of Malenia - 500g"
Player B: Opens trade window, offers 500g
          ↓
Normal trade completes
Item changes hands
          ↓
(Behind the scenes: Provenance updated on chain)
```

**No crypto friction.** No wallets required. No gas fees visible to users. It just works like normal game trading.

### Real Value, Real Scarcity

The value of forged items comes from **real scarcity**:

```
WHY A THUNDERFURY IS VALUABLE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Only ~0.1% of WoW players ever got it
2. The achievement is UNOBTAINABLE now
3. Only X Thunderfuries can EVER exist in Dreadland
4. The item has real combat utility (chain lightning)
5. It carries visible provenance (forged 2007, traded 3x)

The blockchain doesn't CREATE value.
It VERIFIES and PRESERVES value that already exists.
```

### The "Cash Out" Option

Players who want real-money value can access it:

```
OPTIONAL CASH-OUT PATH:
━━━━━━━━━━━━━━━━━━━━━━
1. Player has valuable forged item
2. Lists on in-game marketplace
3. Buyer pays with:
   - Gold (stays in-game economy)
   - Credits (convertible currency)
4. Seller can withdraw credits (minus fee)

Most players will NEVER cash out.
But knowing they COULD adds psychological weight.
```

### Why Items Feel Valuable

The magic isn't the blockchain—it's **storytelling through provenance**:

```
INSPECTING A LEGENDARY FORGED ITEM:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
┌─────────────────────────────────────────────────┐

│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│ "Did someone say Thunderfury?"                  │
```

## Adding New Games: Checklist

Before adding ANY new game:

- [ ] Game scores 25+ on evaluation template
- [ ] At least 2 achievements pass "Holy Shit" test
- [ ] Items can be represented in LPC pixel art style
- [ ] Theme colors don't clash with existing themes
- [ ] Doesn't push us over category quota

Before adding ANY new achievement:

- [ ] Global unlock % < 20%
- [ ] Passes 5-second recognition test
- [ ] Associated item is distinct from existing items
- [ ] Doesn't duplicate existing mapping functionality
- [ ] Effect has a native Dreadland equivalent
- [ ] Consider market impact (will this flood supply of similar items?)

---

## Red Lines (Never Do)

1. **Never map achievements > 30% unlock rate** - These are not prestigious
2. **Never create forged body armor sets** - That's Dreadland's domain
3. **Never create effects without native equivalents** - Every forged power must be earnable in Dreadland
4. **Never map more than 5 achievements per game** - Diminishing returns
5. **Never rush to add items** - Every addition dilutes the existing pool
6. **Never let forged items exceed native power ceiling** - Forged = fast track, not pay-to-win
7. **Never allow achievement re-forging** - One forge per achievement per account, ever
8. **Never hide provenance** - Trade history is always visible to maintain trust
9. **Never make crypto required** - Traditional gamers must never hit a wallet popup

## Success Metrics

How do we know the forge system is working?

| Metric | Target | How to Measure |
|--------|--------|----------------|
| "What's that?" rate | High | Players asking about forge items in chat |
| Account linking rate | >30% | Users linking external providers |
| Item variety in lobbies | Diverse | Not everyone wearing same forge item |
| Native item prominence | >70% | Endgame players mostly in Dreadland gear |
| "I need to get that" mentions | Frequent | Players discussing earning specific achievements |
| **Power parity** | Equal | Top forged vs top native builds have same DPS ceiling |
| **External game activity** | Measurable | Players returning to grind achievements in other games |
| **Effect diversity** | Varied | Players choosing items for effects, not just looks |
| **Trading volume** | Healthy | Active marketplace with regular transactions |
| **Price discovery** | Organic | Legendary items command premium, rares are accessible |
| **Provenance engagement** | >10% | Players viewing item history/certificates |
| **Cash-out rate** | <5% | Most players keep items in-game (healthy sign) |
