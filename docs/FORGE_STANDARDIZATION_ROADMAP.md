# Forge Item Standardization Roadmap

**Version**: 1.0
**Date**: 2025-12-14
**Current State**: v2.0.0 (116 items across 42 themes)
**Target State**: v3.0.0+ (~140-160 items with standardized distribution)

---

## Executive Summary

This roadmap defines the path to standardize forge item distribution across all games/IPs in the Mantle ecosystem. The goal is to create a **balanced, consistent experience** where most games have **3-4 items** each, with exceptions for games with massive content libraries (Blizzard franchises, FromSoftware games, etc.).

**Key Metrics**:
- **Current**: 116 items across 42 themes (average: 2.76 items/theme, median: 1 item)
- **Target**: ~140-160 items across 42+ themes (average: 3.5 items/theme, median: 3 items)
- **Growth**: +24 to +44 items needed (~21-38% increase)

## Standardization Policy

### Standard Item Counts

| Category | Target | Justification |
|----------|--------|---------------|
| **Standard** | **3-4 items** | Normal distribution for most games |
| **Blizzard Franchises** | **9 items each** | Equal representation across WoW, Diablo, Overwatch, StarCraft |
| **FromSoftware Outliers** | **7-11 items** | Elden Ring (11), Dark Souls (7), maintain high counts due to massive achievement pools |
| **Platform Providers** | **5-6 items** | GitHub (6), Discord (5) - represent platform achievements, not single games |

### Rarity Distribution (per game)

For 3-item games:
- 1 Legendary
- 1 Epic
- 1 Rare

For 4-item games:
- 2 Legendary
- 1 Epic
- 1 Rare

For 9-item games (Blizzard):
- 4 Legendary
- 3 Epic
- 2 Rare

## Design Philosophy Adherence

### Maintained Principles

✅ **Provider Diversity**: All 7 providers represented (Steam, Battle.net, Xbox, PlayStation, Discord, GitHub, Roblox)
✅ **Accessibility Mix**: Legendary (40%), Epic (25%), Rare (20%), Uncommon (10%), Common (5%)
✅ **"Holy Shit" Test**: All items pass the recognition/prestige test
✅ **No Duplicates**: Avoid creating similar items across games
✅ **Popular Games First**: Prioritize games with 100K+ monthly players

### New Principles

🆕 **3-4 Item Standard**: Most games should have 3-4 items
🆕 **Equal Blizzard Distribution**: All Blizzard franchises get 9 items
🆕 **FromSoftware Exception**: 7-11 items for games with massive achievement pools
🆕 **Phase-by-Phase Growth**: Gradual expansion over multiple versions

## Notes

- **API Integration**: Phase 1 used placeholder achievement IDs. Future phases should verify actual achievement API names.
- **Asset Creation**: Each new item requires 64x64 icon + optional LPC sprite sheet (for weapons/armor)
- **Testing**: User must test in Godot before committing each batch
- **Flexibility**: This roadmap is a guide, not a strict requirement. Adjust based on user feedback and game popularity shifts.
- **Long-Term Vision**: By v3.0.0, the forge system should feel balanced and comprehensive, with no major gaps in game representation.
