## Philosophy: Achievement → Item Fantasy Mapping

The key insight: **Achievement TYPE should logically map to item SLOT**

### Mapping Framework

| Achievement Category | Natural Item Slots | Fantasy Reason |
|---------------------|-------------------|----------------|
| **Exploration/Travel** | Boots, Capes | "You walked a thousand miles" → boots make sense |
| **Crafting/Building** | Hands, Rings | Craftsman's gloves, artisan rings |
| **Combat/Boss Kills** | Weapons, Shields, Chest Armor | The warrior's trophy |
| **PvP/Competitive Rank** | Helms, Shields, Weapons | Champion's regalia |
| **Collection/Completion** | Amulets, Accessories | Collector's tokens |
| **Stealth/Skill** | Capes, Hands, Daggers | Silent tools of the trade |
| **Magic/Lore** | Staffs, Rings, Amulets | Arcane knowledge embodied |
| **Survival/Endurance** | Chest, Legs, Boots | Survivor's armor |
| **Social/Community** | Accessories, Badges | Recognition pieces |
| **Legacy/Unobtainable** | ANY slot at Legendary | Historical prestige |

## Notes

- **No new Legendary weapons** - Already over-represented
- **Focus on defensive/utility slots** - Players need full loadout options
- **Achievement accessibility** - Rare items should be from achievements most players can earn
- **Fantasy coherence** - Every item must "make sense" from its source achievement
- **Asset pipeline** - Each new item needs icon + sprite (prioritize icons first)
